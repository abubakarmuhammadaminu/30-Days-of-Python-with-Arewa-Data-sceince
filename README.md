# 🐍 30 Days of Python Challenge

Welcome to my **30 Days of Python Challenge**! This repository is dedicated to documenting my daily journey, code snippets, and projects as I learn and master Python from the ground up over the next 30 days.

## 🎯 Goal
To build a rock-solid foundation in Python by coding for at least **1 hour every day** for 30 consecutive days, moving from basic syntax to building functional applications.

---

## 🚀 How to Use This Repo

Every day has its own dedicated folder containing:
* `README.md` explaining the day's concept.
* `main.py` containing the code written.
* Any exercises or challenges completed.

To run any script locally:
```bash
# Clone the repository
git clone https://github.com

# Navigate to the specific day
cd 30-days-of-python-with-Arewa-Data science/Day_1

# Run the script
python main.py
```
